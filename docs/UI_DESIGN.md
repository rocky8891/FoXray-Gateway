# FoXray UI 设计规范

适用于 FoXray Gateway 各版本。以已确认并保留的设计为准。控件尺寸及模块细节参考各版本的控件规范。

## 视觉与交互

- 按钮的默认、悬浮、按下、选中、键盘焦点和禁用状态统一沿用 v0.9.65 的共享效果。普通操作用主题中性色，选中项用主题强调色，破坏性操作用危险色。常用文档等背景接近的区域也要保持悬浮可辨识。共享按钮背景、边框和模糊效果由主题统一控制。
- 常规按钮 42px，紧凑按钮 32px，图标与文字间距 6px。纯图标按钮使用正方形点击区并提供可访问名称。标题、图标和同行操作沿同一水平中线对齐。字段说明优先放在就近的 i 入口，与前方内容间隔 8px。
- 同层卡片统一使用主题背景、边框、圆角和内边距。相邻卡片顶边对齐，分组间距使用共享变量。帮助中心分类用一张深色底层卡片承托，与文档区对齐。分类名称左对齐，数量右对齐，按钮间距 8px。窄屏保留内边距。

## 表格、筛选与弹窗

- 所有表格的首列和尾列固定宽度且不可调整，包括弹窗、嵌套区域和设置表格。宽度按表头、图标、内边距和内容最大可预期长度分配。长文本可以省略，完整值通过悬浮提示或详情查看。选择、序号、操作等工具列也使用固定宽度。
- 表头及所有单元格内容垂直居中。尾列表头、文字、时间及操作按钮同时水平居中，共用一条中心线。中间数据列可以调整，窄屏在表格内部横向滚动。
- 筛选重置分清作用范围。列内「重置」只清除当前列条件，工具栏「重置所有筛选」清除全表条件、搜索和选择。弹窗、下拉和操作菜单共用主题样式，支持键盘、Esc 和视口边缘避让。
- 涉及网络规则或管理链路的操作保留预览、确认和回退。需要确认时显示明确的确认入口、实际变更与影响。任务失败时显示原因和可安全展示的日志，任务状态与操作结果一致。

## 首页与设置

- 首页和其他页面的显示范围默认均为 95%。首页设为 100% 时，内容应填满可用区域。侧边工具栏和内容发生任何重叠时自动收起，空间恢复后恢复正常位置。弹出工具栏使用紧凑、对齐的按钮，去掉额外卡片边框和展开时的绿色标识。随机主题操作保留当前展示内容与顺序，界面只显示必要反馈。
- 恰好显示两张主体卡片时提供「上下均分」「左右均分」，其他数量回到适用布局。时间和数据状态属于页脚。仅显示一个 WireGuard 接口时可以使用接口卡片样式。圆形指标变大时，圆内名称、数值和图标随各自圆径等比例缩放。
- 保留设置中心及监控、日志、服务页的就地设置入口。多个入口共用同一表单和配置来源。「全局设置」用标题栏齿轮图标，「账号与登录」集中管理账号、登录方式、会话时长和首页常驻监控。
- 保存工具栏或单个保存按钮始终放在设置项卡片外、卡片容器内的右下角，与设置项卡片的右边缘对齐。外层容器的背景和内边距覆盖工具栏。合并设置卡片后共用一条工具栏，依次放置「恢复默认」「放弃保存」「保存并应用」。恢复默认只修改草稿。
- 「页面读取与刷新」在全局设置和「监控 → 设置 → 主页」均可编辑，两处读写同一配置。同一页面最多出现一张「配置与同步」卡片，位于配置区末尾，聚合当前页各设置卡片的保存、恢复默认和放弃修改。单卡片保存可以保留。
- 监控采集、主动探测、历史写入、历史保留和页面刷新按实际含义命名。流量、延迟与连接的历史写入间隔统一在监控设置编辑，服务设置保留主动探测、自动选优和 Peer 策略等业务设置。

## 监控与运维信息

- 首页和服务器监控页共享采集结果与指标选择。读到的零值显示为 `0` 或相应格式，待采集、缺测或过期显示 `—`，并在状态或详情说明原因。过期判断使用对应模块当前生效的后台采集间隔。
- WireGuard 列表摘要优先显示 Peer、对端地址、状态和最近检测或握手时间。连续次数、失联阈值、路由撤销结果放在 Peer 详情。区分探测状态和握手记录。失联自动撤路由由用户选择开启。
- 防火墙按用途使用「域内规则」「域间规则」「SNAT」「DNAT」「规则诊断」。域内规则合并常规规则、服务放行及高级规则的列表入口。高级选项放进规则编辑。SNAT 标明出接口，DNAT 标明入接口。显示规则来源、实际状态和可编辑性，清楚区分已读取、未确认、仅运行时和已持久化。涉及多种规则来源时保留各自的管理归属。

## 界面验收

表格检查首尾宽度、排序和筛选后对齐，并验证窄屏横向滚动。按钮检查明暗主题中的悬浮、按下、选中、键盘焦点和禁用状态。设置页从集中入口和模块入口分别打开，验收实际保存结果以及页面上统一保存卡片的数量。首页检查 95% 和 100%、双卡均分、单 WireGuard 接口和侧栏发生重叠时的自动隐藏。监控截图应覆盖零值、有效值与真正缺测三种情况。
