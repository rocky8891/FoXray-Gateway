# FoXray Gateway v0.9.51 管理登录与 HTTPS

适用于 `foxray_v0.9.51`。安装或升级后，使用初始账号登录。初始登录要求设置新密码。之后可从「设置 → FoXray → 管理用户」新增账号、修改用户名或密码，以及退出登录。当前版本的管理账号具有相同权限。管理用户卡片支持用户名和密码、仅密码、关闭认证三种登录方式。仅密码方式使用所选账号的密码。关闭认证后，能访问管理地址的人可以直接操作应用。

「设置 → FoXray → HTTPS」可指定 HTTPS 端口，默认 `18443`。启用后关闭 HTTP 管理访问。可选的 HTTP 跳转端口只接收页面跳转。升级会保留已有证书和 HTTPS 端口，原 HTTP 管理地址不再提供界面。已有证书可选择「保留现有证书」单独修改端口。

- **自签名**填写实际使用的域名或 IP。浏览器需要信任该证书。
- **第三方证书**导入完整 PEM 链和对应的 PEM 私钥。建议在 HTTPS 页面导入，或通过 SSH 隧道打开本机管理入口导入。
- **Let's Encrypt HTTP 验证**先安装 Certbot。填入公共域名或 DDNS 域名和电子邮箱，确保公网 TCP 80 可访问网关的验证路径。系统会在验证时监听 TCP 80，或者复用 FoXray 自己在 TCP 80 的跳转入口。签发成功后会定期检查续期并载入新证书。
- **Cloudflare DNS 验证**先在网关安装 Certbot 及 `certbot-dns-cloudflare` 插件。通过管理机将具备该 DNS 区域编辑权限的 API 凭据配置到 `/opt/foxray/private/acme/cloudflare.ini`，并设为 `0600`。配置项名为 `dns_cloudflare_api_token`。随后在页面输入域名与邮箱并保存。签发后，FoXray 每 12 小时检查是否需要续期，成功后直接使用新证书。签发或续期失败可在 HTTPS 卡片中查看提示。

未启用 HTTPS 的网关可用 HTTP 完成首次登录。登录后的备份支持浏览器下载或写入网关目录，详见同版本配置备份与恢复手册。
