# FoXray Gateway v0.9.49 管理登录与 HTTPS

适用于 `foxray_v0.9.49`。安装或升级后，使用初始账号登录。初始登录要求设置新密码。之后可从「设置 → 全局 → 管理用户」新增账号、修改用户名或密码，以及退出登录。当前版本的管理账号具有相同权限。

「设置 → 全局 → HTTPS」可启用 `18443/tcp` 的 HTTPS 管理入口。HTTP 继续通过现有管理端口提供服务。访问范围沿用受信任内网限制，如防火墙拦截 18443，请在网关明确放行所需管理网段。

- **自签名**填写实际使用的域名或 IP。浏览器需要信任该证书。
- **第三方证书**导入完整 PEM 链和对应的 PEM 私钥。建议在 HTTPS 页面导入，或通过 SSH 隧道打开本机管理入口导入。
- **Cloudflare DNS 验证**先在网关安装 Certbot 及 `certbot-dns-cloudflare` 插件。通过管理机将具备该 DNS 区域编辑权限的 API 凭据配置到 `/opt/foxray/private/acme/cloudflare.ini`，并设为 `0600`。配置项名为 `dns_cloudflare_api_token`。随后在页面输入域名与邮箱并保存。签发后，FoXray 每 12 小时检查是否需要续期，成功后直接使用新证书。签发或续期失败可在 HTTPS 卡片中查看提示。

升级后可继续使用 HTTP 入口完成首次登录。登录后的备份支持浏览器下载或写入网关目录，详见同版本配置备份与恢复手册。
