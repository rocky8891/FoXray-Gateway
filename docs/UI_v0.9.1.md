# FoXray Gateway 0.9.1 控件规范

适用于完整产品版本 **0.9.1**。按钮规格按用途选择，同一用途不因页面、卡片、弹窗或屏幕宽度而改变。

| 类型 | 高度 | 字号 / 字重 / 行高 | 使用位置 |
| --- | --- | --- | --- |
| 常规按钮 | 42px | 13px / 650 / 20px | 页面工具栏、新增、导入、刷新、保存、确认 |
| 紧凑按钮 | 32px | 13px / 650 / 20px | 表格行、卡片行、分页、筛选浮层、关闭、复制、任务控件 |
| 纯图标按钮 | 与同排按钮等高，宽高相等 | 图标 18px | 更多、筛选、排序、主题、关闭 |

统一采用产品字体、6px 圆角、1px 边框、6px 图文间距。工具栏中的搜索框与按钮等高。表格操作列仍保持窄列、无左分隔线，标题与按钮中心线对齐。

主要操作使用绿色；普通操作使用中性底色；破坏性操作使用红色。禁用按钮保留几何和字体，降低透明度；键盘焦点使用清晰描边。纯图标按钮必须具备可访问名称。

导航和分段选择保留其选中状态；独立的列表、宫格按钮采用常规圆角和间距。真正的组合操作（例如“检测 + 检测设置”）仅连接处使用直角。任务页签保持底部绿线，不以背景色或字体颜色切换激活状态。

`i` 说明、表格排序三角、文字链接、颜色面板和图表交互是专用控件，不套用普通操作按钮尺寸。说明文字保持较小字号。

## 实现约定

- `frontend/src/button_system.css` 是按钮几何和字体的统一来源，在页面布局样式之后加载。
- 共用 `Button` 支持 `size="regular"`、`size="compact"` 和 `iconOnly`；默认使用常规尺寸，表格等紧凑容器统一选择紧凑尺寸。
- 旧原生按钮使用 `.button` 同样遵循规范；新增操作按钮优先使用 `Button`。
- 页面只负责布局和语义状态，不另写按钮字号、高度、字重和圆角。新增尺寸必须先更新本规范和公共变量。
- 修改后检查深浅主题、禁用和焦点、菜单、表格、弹窗及 320px 窄屏；对比实际计算样式，不仅依靠截图。
