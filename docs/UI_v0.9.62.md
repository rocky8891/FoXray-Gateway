# FoXray Gateway v0.9.62 控件规范

适用版本：程序、前端及配套工具 v0.9.62。

## 按钮与导航

常规按钮高度 42px，紧凑按钮高度 32px；产品字体、字号 13px、字重 650、行高 20px，图标 18px，图文间距 6px，使用统一圆角变量。工具栏与配置保存使用常规按钮；表格、分页、关闭、复制等使用紧凑按钮。纯图标按钮宽高相等，必须有可访问名称。

普通操作默认中性色；选中状态和有草稿变更的保存按钮高亮；破坏性操作使用危险色。启用、停用按钮始终显示，仅改变是否可用。各层导航使用同一套普通／选中颜色。

## 表格、筛选与选择

全应用原生单选下拉框统一使用主题面板，保留原始select元素、表单名称、disabled／required、ref及React变更回调。长列表支持独立搜索，短列表直接展示，支持方向键、Enter、Esc及外部点击关闭；弹窗和嵌套筛选中的菜单留在所属容器内并自动避让视口边缘。分页与紧凑控件继续由原控件计算宽度。可编辑候选地址仍支持自由输入，使用主题候选列表替代浏览器原生datalist。

原生控件面板、图标选择、接口多选、主题菜单及操作菜单共用页面的圆角、边框、背景和文字变量。长列表滚动使用统一轨道、上下按钮和可拖动滑块，支持滚轮及键盘；点击滚动控件不会因失焦关闭菜单。

防火墙普通服务放行与高级规则的预定义服务使用同一可搜索选择器，读取系统已安装服务清单；打开时重置搜索并展示完整列表，选择值与搜索词分开。菜单沿用主题背景、文字、选中与悬浮色，支持方向键、Enter、Esc及点击外部关闭。新建规则不预填ssh，服务为空时禁止生成预览；空清单明确提示刷新，保留现有预览、确认和回退流程。

所有表格选择列 36px、序号列 42px、操作／详情列 48px；中间数据列均分剩余宽度。操作列不显示左分隔线，标题与按钮中心一致，按钮距右边约 8px。空间不足时表格内部滚动，移动布局保持排序与筛选可用。

刷新位于管理工具栏左侧；防火墙的服务刷新、启停和自启操作位于标题右侧。搜索优先收缩，必要时变为打开输入浮层的图标。

筛选组合不直接占用工具栏：有实际条件或勾选对象时，重置所有筛选按钮高亮，悬停显示完整条件／选择信息。重置同时清空筛选与跨分页勾选。筛选浮层使用“重置”和“完成”，Esc 或点击外部关闭。

列表与宫格共用选择；宫格选中底色与悬停效果协调。批量接口、路由和策略规则使用一份预览、应用、确认与回退计划；回环／VPN 保护和受管理归属检查由后端保持。

## 标题、说明与状态卡片

说明统一放入就近 i 入口；i 不参与标题文字高度与按钮中线对齐计算。配置与同步标题、页面标题和同行操作按同一水平中线对齐，窄屏自然分行。

服务状态、版本指标和防火墙区域状态采用相同的小卡片：最小高度 74px、内边距 12px/16px、内容间距 6px；标签 11px/400/18px，数值 14px/700/20px。防火墙的区域目标、绑定接口、绑定来源卡片放在管理接口右侧。

版本页不重复显示顶部结论和来源段落；来源与可用 URL 放入检查更新 i，确认是最新版的当前版本值显示绿色。只读详情使用顶部复制详情，保留右上角关闭和 Esc。

## 主页与布局

服务器监控页运行状态圆环的SVG描边从9减为4.5，底轨与彩色进度弧同时减细一半；不改变圆径、百分比或文字布局。

上方主卡片、下方并列卡片布局中，“四圆方形”保持2×2排列，圆径不超过同一可用宽高下“四圆心形”的圆径。其他布局不应用此缩小约束。

各圆形指标使用命名的辅助功能分组，按圆形外接方框暴露控件边界。圆径及定位对齐整数CSS像素；主页服务器进度环恢复4px粗细及较暗底轨，其他卡片保留2px圆框，进度环外沿与元素外框相切。悬浮高亮背景并将外框设为透明，保持边框占位、辅助功能外接框及几何尺寸不变；服务器指标除外，悬浮保留完整进度环或矩形外框，仅高亮背景。小圆与大圆保留布局自身的比例。

上方服务器主卡片按自身圆径与用户字号基准适配，不使用宽而浅的波浪虚拟圆径压缩字号；优先保留常规字号，空间不足再缩小。其他卡片四圆混合的大圆与同卡片空间下四圆波浪共用字号基准（200px圆径对应用户字号设置）；波浪和混合布局随圆径调整标题、数值及图标字号，最小缩放比例0.5。文字宽度使用固定代表值预留，避免实时数值变化造成字号跳动。WireGuard自动圆径在宫格中采用相邻混合布局大圆的相同几何比例，随卡片空间增大或缩小；正常浏览器／显示缩放保持生效，不设427px固定上限。显式设置的圆径继续受可用空间限制。

服务器数值沿用统一卡片配色：平均负载紫色、CPU蓝色、内存绿色、根分区橙色，矩形与圆形样式一致。

UI操作的请求标识关联对应操作日志和任务结果，并在当前浏览器自动标为已读；后台操作不带UI请求标识，保留原有未读提醒。阅读状态继续保存在浏览器本地。

全局配置位于设置二级菜单最后。首页标题栏自动隐藏默认关闭；100% 内容宽度时，右侧工具条自动收起。边缘支持鼠标、点击和键盘聚焦展开。

时间与数据状态单行居中；较窄时在该容器内滚动。节点一览的指定节点通过可搜索、全选、按列排序和跨页选择的弹窗设置，勾选修改草稿，保存后改变显示。

## 实现与验证

按钮几何来自 `frontend/src/button_system.css`，公共表格与说明来自 `ui.tsx`，列表控制来自 `list_controls.tsx`。页面不得另设不同的按钮字号、字重或圆角；半径检查脚本为 `check_radius_v0.9.62.mjs`。

修改公共控件后验证深浅主题、禁用／选中／焦点、键盘、弹层及窄屏。界面检查使用模拟写请求，不能替代 Linux 内核与独立回退验证。


## 2026-11-22 正式更新

网络与防火墙保留统一标题和二级导航。统计卡片仅在对应筛选激活时高亮，地址族直接切换；路由表显示 ID 与名称。网络待确认变更展示服务端截止时间，可确认保留或立即回退。接口标签与 IP 地址保持单行，长内容保留完整提示。主页指标字号不随实时数值变化。

防火墙区域默认行为支持 default、ACCEPT、DROP、REJECT，进入变更预览和影响提示。默认仅修改永久配置；立即应用须额外确认全局重载，运行时与永久配置存在未同步差异时阻止重载。未确认的已应用变更自动回退。


## WireGuard备注与节点分页（0.9.62）

WireGuard → 接口 → 添加或编辑表单可填写备注；现有接口可使用操作 → 编辑备注单独修改，空值清除备注，最多200字符。备注以FoXray专用注释保存在本机wg-quick配置内，与接口名、服务端／客户端角色和保护状态分开。仅改备注可在接口运行时进行，不触发服务或路由操作；生成预览并应用后，在120秒内确认，否则独立回退。修改运行中的地址、Peer 等配置时，应用会自动先停止所选接口、保存新配置并重新启动；失败或未确认会恢复原配置及运行状态。可修改接口名称并同步其自启与区域绑定；名称冲突、自定义钩子硬编码旧名或手工路由引用旧名时会阻止重命名。

节点一览分页默认使用“自动（N项/页）”，按当前页面高度调整。手动选择10／20／50／100项后，容量不再限制用户选择，超出可视区域可以滚动；选回自动恢复按高度分页。节点管理的名称列使用剩余宽度，辅助列保持紧凑。网络与防火墙统计数字保持分类配色，未筛选时卡片不高亮；深色统计卡片底色统一为rgb(28,35,47)。


## 诊断阅读状态与标题样式（0.9.62）

从界面执行诊断且结果自动显示后，对应任务和具有相同job_id的关联日志会在当前浏览器标为已读；未展示的后台结果保持原阅读状态。分页框根据最长可能选项的实际字宽预留箭头空间；WireGuard的受保护状态单独换行。防火墙服务管理不使用图标底块，区域标题图标统一绿色并居中对齐，Xray与WARP服务管理使用产品图标。

随机主题位于主页的服务总览。正式服务在一分钟内没有新随机操作后保存；只读预览仅在当前页面试用，不发送保存请求。


## 防火墙独立状态加载（0.9.62）

服务状态由独立轻量接口读取，首次打开先显示运行状态、开机自启，规则仍继续加载。规则完整前区域配置与规则编辑保持不可用；独立服务读取失败显示未确认，不能使用规则成功掩盖状态查询失败。刷新同时重新查询服务及规则；切换区域不需要重新等待服务状态。后端复用同次区域详情，取消重复的允许服务、地址伪装和区域策略查询。管理工具、区域与范围标题统一字体；策略状态、绑定接口、配置来源和允许服务使用主题绿色，无下划线。
