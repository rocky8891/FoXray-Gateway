# FoXray Gateway v0.9.67 控件规范

适用版本：程序、前端及配套工具 v0.9.67。

## 按钮与导航

常规按钮高度 42px，紧凑按钮高度 32px；产品字体、字号 13px、字重 650、行高 20px，图标 18px，图文间距 6px，使用统一圆角变量。工具栏与配置保存使用常规按钮；表格、分页、关闭、复制等使用紧凑按钮。纯图标按钮宽高相等，必须有可访问名称。

普通操作默认中性色；选中状态和有草稿变更的保存按钮高亮；破坏性操作使用危险色。启用、停用按钮始终显示，仅改变是否可用。各层导航使用同一套普通／选中颜色。

## 表格、筛选与选择

全应用原生单选下拉框统一使用主题面板，保留原始select元素、表单名称、disabled／required、ref及React变更回调。长列表支持独立搜索，短列表直接展示，支持方向键、Enter、Esc及外部点击关闭；弹窗和嵌套筛选中的菜单留在所属容器内并自动避让视口边缘。分页与紧凑控件继续由原控件计算宽度。可编辑候选地址仍支持自由输入，使用主题候选列表替代浏览器原生datalist。

原生控件面板、图标选择、接口多选、主题菜单及操作菜单共用页面的圆角、边框、背景和文字变量。长列表滚动使用统一轨道、上下按钮和可拖动滑块，支持滚轮及键盘；点击滚动控件不会因失焦关闭菜单。

防火墙普通服务放行与高级规则的预定义服务使用同一可搜索选择器，读取系统已安装服务清单；打开时重置搜索并展示完整列表，选择值与搜索词分开。菜单沿用主题背景、文字、选中与悬浮色，支持方向键、Enter、Esc及点击外部关闭。新建规则不预填ssh，服务为空时禁止生成预览；空清单明确提示刷新，保留现有预览、确认和回退流程。

所有表格选择列 36px、序号列 42px、操作／详情列 48px；中间数据列均分剩余宽度。操作列不显示左分隔线，标题与按钮中心一致，按钮距右边约 8px。空间不足时表格内部滚动，移动布局保持排序与筛选可用。

刷新位于管理工具栏左侧；防火墙的服务刷新、启停和自启操作位于标题右侧。搜索优先收缩，必要时变为打开输入浮层的图标。

筛选组合不直接占用工具栏：有实际条件或勾选对象时，重置所有筛选按钮高亮，悬停显示完整条件／选择信息。重置同时清空筛选与跨分页勾选。筛选浮层使用“重置”和“完成”，Esc 或点击外部关闭。

列表与宫格共用选择；宫格选中底色与悬停效果协调。批量接口、路由和策略规则使用一份预览、应用、确认与回退计划；回环／VPN 保护和受管理归属检查由后端保持。

## 标题、说明与状态卡片

说明统一放入就近 i 入口；i 不参与标题文字高度与按钮中线对齐计算。配置与同步标题、页面标题和同行操作按同一水平中线对齐，窄屏自然分行。

服务状态、版本指标和防火墙区域状态采用相同的小卡片：最小高度 74px、内边距 12px/16px、内容间距 6px；标签 11px/400/18px，数值 14px/700/20px。防火墙的区域目标、绑定接口、绑定来源卡片放在管理接口右侧。

版本页不重复显示顶部结论和来源段落；来源与可用 URL 放入检查更新 i，确认是最新版的当前版本值显示绿色。只读详情使用顶部复制详情，保留右上角关闭和 Esc。

## 主页与布局

服务器监控页运行状态圆环的SVG描边从9减为4.5，底轨与彩色进度弧同时减细一半；不改变圆径、百分比或文字布局。

上方主卡片、下方并列卡片布局中，“四圆方形”保持2×2排列，圆径不超过同一可用宽高下“四圆心形”的圆径。其他布局不应用此缩小约束。

各圆形指标使用命名的辅助功能分组，按圆形外接方框暴露控件边界。圆径及定位对齐整数CSS像素；主页服务器进度环恢复4px粗细及较暗底轨，其他卡片保留2px圆框，进度环外沿与元素外框相切。悬浮高亮背景并将外框设为透明，保持边框占位、辅助功能外接框及几何尺寸不变；服务器指标除外，悬浮保留完整进度环或矩形外框，仅高亮背景。小圆与大圆保留布局自身的比例。

上方服务器主卡片按自身圆径与用户字号基准适配，不使用宽而浅的波浪虚拟圆径压缩字号；优先保留常规字号，空间不足再缩小。其他卡片四圆混合的大圆与同卡片空间下四圆波浪共用字号基准（200px圆径对应用户字号设置）；波浪和混合布局随圆径调整标题、数值及图标字号，最小缩放比例0.5。文字宽度使用固定代表值预留，避免实时数值变化造成字号跳动。WireGuard自动圆径在宫格中采用相邻混合布局大圆的相同几何比例，随卡片空间增大或缩小；正常浏览器／显示缩放保持生效，不设427px固定上限。显式设置的圆径继续受可用空间限制。

服务器数值沿用统一卡片配色：平均负载紫色、CPU蓝色、内存绿色、根分区橙色，矩形与圆形样式一致。

UI操作的请求标识关联对应操作日志和任务结果，并在当前浏览器自动标为已读；后台操作不带UI请求标识，保留原有未读提醒。阅读状态继续保存在浏览器本地。

全局配置位于设置二级菜单最后。首页标题栏自动隐藏默认关闭；100% 内容宽度时，右侧工具条自动收起。边缘支持鼠标、点击和键盘聚焦展开。

时间与数据状态单行居中；较窄时在该容器内滚动。节点一览的指定节点通过可搜索、全选、按列排序和跨页选择的弹窗设置，勾选修改草稿，保存后改变显示。

## 实现与验证

按钮几何来自 `frontend/src/button_system.css`，公共表格与说明来自 `ui.tsx`，列表控制来自 `list_controls.tsx`。页面不得另设不同的按钮字号、字重或圆角；半径检查脚本为 `check_radius_v0.9.67.mjs`。

修改公共控件后验证深浅主题、禁用／选中／焦点、键盘、弹层及窄屏。界面检查使用模拟写请求，不能替代 Linux 内核与独立回退验证。


## 2026-11-22 正式更新

网络与防火墙保留统一标题和二级导航。统计卡片仅在对应筛选激活时高亮，地址族直接切换；路由表显示 ID 与名称。网络待确认变更展示服务端截止时间，可确认保留或立即回退。接口标签与 IP 地址保持单行，长内容保留完整提示。主页指标字号不随实时数值变化。

防火墙区域默认行为支持 default、ACCEPT、DROP、REJECT，进入变更预览和影响提示。默认仅修改永久配置；立即应用须额外确认全局重载，运行时与永久配置存在未同步差异时阻止重载。未确认的已应用变更自动回退。


## WireGuard备注与节点分页（0.9.67）

WireGuard → 接口 → 添加或编辑表单可填写备注；现有接口可使用操作 → 编辑备注单独修改，空值清除备注，最多200字符。备注以FoXray专用注释保存在本机wg-quick配置内，与接口名、服务端／客户端角色和保护状态分开。仅改备注可在接口运行时进行，不触发服务或路由操作；生成预览并应用后，在120秒内确认，否则独立回退。修改运行中的地址、Peer 等配置时，应用会自动先停止所选接口、保存新配置并重新启动；失败或未确认会恢复原配置及运行状态。可修改接口名称并同步其自启与区域绑定；名称冲突、自定义钩子硬编码旧名或手工路由引用旧名时会阻止重命名。

节点一览分页默认使用“自动（N项/页）”，按当前页面高度调整。手动选择10／20／50／100项后，容量不再限制用户选择，超出可视区域可以滚动；选回自动恢复按高度分页。节点管理的名称列使用剩余宽度，辅助列保持紧凑。网络与防火墙统计数字保持分类配色，未筛选时卡片不高亮；深色统计卡片底色统一为rgb(28,35,47)。


## 诊断阅读状态与标题样式（0.9.67）

从界面执行诊断且结果自动显示后，对应任务和具有相同job_id的关联日志会在当前浏览器标为已读；未展示的后台结果保持原阅读状态。分页框根据最长可能选项的实际字宽预留箭头空间；WireGuard的受保护状态单独换行。防火墙服务管理不使用图标底块，区域标题图标统一绿色并居中对齐，Xray与WARP服务管理使用产品图标。

随机主题位于主页的服务总览。正式服务在一分钟内没有新随机操作后保存；只读预览仅在当前页面试用，不发送保存请求。


## 防火墙独立状态加载（0.9.67）

服务状态由独立轻量接口读取，首次打开先显示运行状态、开机自启，规则仍继续加载。规则完整前区域配置与规则编辑保持不可用；独立服务读取失败显示未确认，不能使用规则成功掩盖状态查询失败。刷新同时重新查询服务及规则；切换区域不需要重新等待服务状态。后端复用同次区域详情，取消重复的允许服务、地址伪装和区域策略查询。管理工具、区域与范围标题统一字体；策略状态、绑定接口、配置来源和允许服务使用主题绿色，无下划线。

## 探测目标与多源 SNAT

WireGuard → 设置 → ICMP 探测中的「对端隧道 IP」以接口为单位展示，可搜索、筛选、调整列宽、逐项编辑或勾选后批量操作。自动识别使用首个候选主机地址；手动模式允许指定单个 IPv4 或 IPv6 地址。批量改为手动会保留各接口各自当前地址，清空地址会关闭该项自动识别。表格操作先进入待保存配置，使用本卡片保存按钮后生效。

防火墙 → SNAT 的源 IP 支持多个 IPv4 地址或 CIDR，以英文逗号分隔，例如 `10.24.254.0/24,192.168.1.0/24`。firewalld 和 iptables 展开为多个匹配条件，nftables 使用地址集合；FoXray 仍以一条规则展示、编辑、启停和回退。重复及被其他来源覆盖的网段会归并。单源输入方式保持兼容。

操作、检测、切换和诊断日志详情将内容标题与复制按钮放在同一行。弹窗主标题为 22px，内容标题为 18px。一级与二级导航按钮背景模糊统一为 20px。

## i 说明与探测目标筛选

页面的 i 说明支持多级有序和无序列表，短格式提示保持简洁。服务运行与开机自启、显示开关与采集开关等分别说明。说明弹层可通过聚焦、Enter 或点击打开，Escape 关闭；长内容在弹层内滚动。

WireGuard「对端隧道 IP」表的保存说明移至标题 i 中，取消标题行总筛选，保留各列筛选。接口、状态、识别方式、对端隧道 IP 和候选地址都可通过列头排序或筛选；工具栏重置按钮同时恢复排序、搜索和所有列筛选，列筛选弹窗统一使用「重置」按钮且只清除当前列条件。勾选与操作列保留其原本用途。

## WireGuard 指标排序与随机主题

在主页编辑预览中，WireGuard 每个接口卡片的上传、下载、延迟、活动连接数可拖动交换位置，也可聚焦指标后用方向键调整。各接口分别保存顺序，接口本身的排列仍独立设置。拖动后点击「保存并应用」生效，不改变 VPN 地址、路由或 Peer 配置。

随机主题保留当前「展示内容」勾选的卡片及顺序；内置、自定义和混搭主题均不能重新启用已隐藏的卡片。随机仅改变对应布局和样式，手动选择主题仍按所选主题内容应用。

i 说明中的短标题与正文统一使用全角冒号，例如「保护状态：系统保护 wg-home 接口」。正文句子仍使用正常句号，多级有序和无序列表继续保留。

## 列筛选交互标准

所有列筛选弹窗中的清除按钮统一命名为「重置」，作用范围是当前列；工具栏的「重置所有筛选」作用于整张表，不改变其范围。WireGuard 探测参数区与目标表之间沿用设置区的 16px 标准间距，不再叠加表格自身的顶部留白。

## 首页直接编辑的范围

首页右侧工具栏的「编辑样式」与设置中的编辑预览共用排序规则。拖动 WireGuard 指标时，只修改对应接口的指标顺序，不修改首页展示卡片或接口数量。按方向键可调整指标位置；取消恢复原顺序且不提交配置，拖回原位后保存按钮恢复为无更改状态。

## 接口保护开关

在 WireGuard 接口表格的行操作选择「接口保护」，或勾选接口后在「批量操作 → 接口保护」中统一设置。混合状态的批次默认建议开启，用户可明确切换到关闭后保存。单项保存与批量保存均只修改保护元数据，不启停接口或更改网络配置。

旧配置保留 wg-home 默认受保护的行为，其他接口默认关闭；显式选择会覆盖名称默认值并持久保存。开启后，接口操作和相关受保护路由修改需要额外确认。关闭保护不取消运行中配置变更确认、参数校验或 VPN 模块归属限制。接口重命名须按原有预览流程确认，保护设置随接口继承。


### WireGuard 接口表筛选与角色

状态列展示服务单元、配置就绪状态和「角色·运行状态」，例如「服务端 · 已启动」。角色来自已保存的接口配置，未指定时显示「未设置角色」。

表头提供接口（名称/备注及保护状态）、状态（启动/停止及角色）、开机自启、接口 IP、监听端口、Endpoint、AllowedIPs、Peer / 隧道状态筛选。关键词按列包含匹配，多个筛选条件取交集；单列重置保留其他列条件，全局重置清除搜索、列条件和选择。

接口保护的单条及批量入口使用蓝色盾牌加号。客户端配置模板的按钮、模板输出和后续确认区域保持独立间距。


## 接入角色与独立方向

接入角色是服务端/客户端的配置模板预设，不决定业务访问方向。两个方向「本地 LAN → VPN」「VPN → 本地 LAN」各自设置允许转发、SNAT、来源和目标，LAN 接口共用。修改接入角色不会翻转已配置的方向。旧配置仍按原语义运行，升级不自动重写接口配置；首次编辑新方向请核对预览。降级到旧程序前应恢复对应版本配置备份，不能假设旧程序理解新方向字段。

LAN → VPN 的默认目标来自启用 Peer 的 IPv4 AllowedIPs，VPN → LAN 的默认目标来自导出目标网段；显式目标只用于匹配，不自动修改 Peer AllowedIPs。禁用全部 Peer 后不会保留自动推导的远端目标规则。来源需为明确 IPv4 CIDR，来源与目标不可混填。

## 帮助中心与统一 i 间距

设置中 FoXray 后方新增帮助中心。提供分类、关键词与模糊搜索、命中高亮、常用文档和本浏览器收藏。收录全部页面静态说明及部署、SELinux、ip_forward、网络、认证与回退指南；具体上下文动态值以原页面为准。自动列宽的 i 入口从所有共享表格移除，使用说明集中到帮助中心。各处其他 i 入口保留。

所有共享 i 说明与前方文字或控件使用 8px 标准间距，自动扣除原有 inline 空白或 flex gap，防止叠加。没有前置主体的独立 i 不额外占位。


### 帮助中心排版与复制操作

帮助中心标题采用指定圆形问号图标，图标与标题文字同行居中；主要面板间距沿用全局 --group-gap（当前 12px），分类和结果区顶边对齐。搜索框沿用列表的 42px 高度和单层焦点边框，在四列桌面布局中等于两张常用文档卡片加中间间距的实际跨度并居中；取消搜索框全局 380px 上限，双列及窄屏使用全宽。

常用文档固定展示八项，收藏优先并由常用手册补足；桌面端四列两行，平板两列，手机一列。卡片为标准 42px 单行高度，图标固定 18px，图标与文字组成的内容组水平及垂直居中，长标题省略显示并可悬停查看全文。

帮助弹窗的收藏、复制全文和复制命令按钮统一 32px。收藏与复制全文位于右侧同组；每段命令的复制按钮在代码框外上方，与全文复制的右边缘对齐。代码内容可以直接选择复制，复制操作不会执行命令。

帮助中心标题旁 i 显示功能说明及项目 GitHub 超链接，说明不再单独占用副标题行。显示更多位于文档列表右下角；加载更早记录、加载更多与显示更多统一使用最新指定的双下箭头图标，颜色继承按钮文字。


### 统一高亮与文档分类

导航、标签、分类、筛选、分页和下拉选项的高亮使用无可见边框、无边框阴影的样式，绿色底色相对原强度减淡三分之一。保留透明边框占位以避免切换时尺寸跳动；键盘 focus-visible 轮廓独立保留，输入框的焦点边框不受影响。

帮助文档按部署与安装、系统环境、账号与 HTTPS、备份与升级、网络与路由、DNS 与 DDNS、Xray、WireGuard、WARP、防火墙、监控与统计、首页与外观、日志与任务、通用操作分别归类。分类总数与全部文档总数一致，关键词搜索与分类筛选取交集。
