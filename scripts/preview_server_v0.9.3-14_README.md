# FoXray 只读预览 v0.9.3-14

适用完整脚本：`preview_server_v0.9.3-14.py`。保留旧版脚本与手册，不替换正式服务。需要 Python 3.9+。

## 本版变化

- 操作菜单统一15px图标框，详情与纳管修正SVG视口留白，可见轮廓与停用图标对齐。
- 接口行使用单个操作入口，包含详情、编辑、启停和删除；编辑IP改名为编辑。VPN／回环保护与原有变更预览、确认及回退流程保留。
- 接口总数显示完整快照数量。点击清除搜索、所有列筛选及已选行，恢复全部接口。
- 页眉设置与管理归属／管理来源采用需求提供的SVG路径，颜色随主题变化。

## 启动

先构建前端：`npm --prefix frontend run build`，复制`frontend/dist`为独立`web`目录。

```sh
python3 preview_server_v0.9.3-14.py --web ./web --listen 192.168.1.8:18881 --upstream http://192.168.1.8:18880
```

本次仅有前端变更，无需启动防火墙规划器。默认部署只允许内网GET读取正式API，所有写入均返回409；配置窗口可查看，不能保存或应用。页面显示版本与只读标识，API查询内容不记日志。不得将预览服务替换为正式后端。

脚本保留可选`--planner`兼容既有隔离防火墙规划器，仅接受环回地址和防火墙计划，禁止应用、确认及回退。本版部署未启用该参数。

## 验证与撤销

```sh
python -m unittest discover -s tests -p test_preview_server_v0_9_3_14.py
```

浏览器验证覆盖搜索／列筛选清除、行选择清除、菜单编辑入口、VPN接口保护、图标可见尺寸及600px布局。正式程序、网页和配置摘要应与预览部署前一致。

本次服务名`foxray-ui-preview-093-14.service`，独立目录`/opt/foxray-previews/v0.9.3-14`。停止该服务即可撤销预览，不影响正式服务。
