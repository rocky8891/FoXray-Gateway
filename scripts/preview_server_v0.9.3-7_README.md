# UI预览服务 v0.9.3-7

适用完整脚本：`preview_server_v0.9.3-7.py`，只需Python3.9+。保留旧预览脚本，当前脚本单独启动，不替换正式程序或网页。

```sh
python3 preview_server_v0.9.3-7.py --web ./web --listen 127.0.0.1:18881 --upstream http://127.0.0.1:18880
```

按实际监听地址修改参数。前端先通过`npm --prefix frontend run build`构建，将`frontend/dist`复制为独立`web`目录。

服务只允许内网来源。静态网页由独立目录提供，API仅转发GET至指定内网管理服务；拦截所有写方法，HEAD也不转发API。状态中强制`read_only=true`，页面标注预览，不能保存配置、启动检测或改变网络。表格搜索、排序、拖动列宽等浏览器交互可用。

请求内容不记录日志，不复制配置、数据库或凭据；上游重定向不跟随。停止预览服务即可撤销入口，正式服务不受影响。发布前应重新构建正式发行包，不能把该脚本作为正式管理程序替代。
