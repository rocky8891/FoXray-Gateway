# FoXray只读预览 v0.9.3-19

适用完整脚本：`preview_server_v0.9.3-19.py`。保留历史脚本与手册，不更新正式服务。

本版给所有分页选择框预留下拉箭头空间；含自动分页的选择框按1～100项可能选项的最长文字实际字宽，加箭头、内边距及边框计算宽度，字体或浏览器缩放后仍容纳完整文字。WireGuard接口与服务列表的受保护状态改为单独一行，备注与保护说明分开显示。

```sh
npm --prefix frontend run build
python3 preview_server_v0.9.3-19.py --web ./web --listen 192.168.1.8:18881 --upstream http://192.168.1.8:18880
```

将frontend/dist复制为独立web目录，需要Python3.9+。本次纯前端预览不启动规划器，API只转发GET，修改请求全部409。接口备注保存和网络变更仅在正式服务执行。停止foxray-ui-preview-093-18.service即可撤销预览。


本版恢复服务总览在只读预览中的随机主题入口，仅本地试用与恢复，不安排自动保存，也不发送设置修改请求。正式服务保持原有随机后一分钟自动保存逻辑。UI诊断结果被自动展示时，按日志ID及job_id联动标为已读；不会把未展示的后台任务批量标为已读。阅读状态沿用当前浏览器的本地存储。
