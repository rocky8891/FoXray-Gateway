# FoXray Gateway v0.9.2

发布日期：2026-11-20。此版本统一管理交互，并修正多选网络对象无法完整提交的问题。

## 主要变化

- 网络接口、受管理路由及策略规则的多选启停合并为一份计划，一次应用、确认与回退；保留回环、VPN、归属和每批数量校验。防火墙区域归属支持多个接口，分别保存运行／永久原区域，应用前再次检查状态。
- 所有表格中间数据列均分，选择、序号和操作列保持窄列；工具栏启用／停用固定显示。筛选组合收进重置按钮悬浮信息，存在条件或勾选时高亮。
- 全局设置移至二级菜单末项；支持首页标题栏自动隐藏、100% 宽度侧边工具条收起，以及时间／数据状态单行显示。节点显示范围改为支持搜索、排序、全选和跨页保留选择的弹窗。
- 服务、版本和区域状态卡片统一高度与字体。防火墙状态卡片置于管理接口右侧，服务动作回到标题右侧。版本来源及 URL 进入检查更新说明，最新当前版本显示绿色。
- 统一按钮、菜单、编辑／启停／纳管等图标，收紧弹窗与空白；只读详情提供复制入口。WARP 检测项目支持即时选择、保留偏好和任务进度／取消。

## 部署与更新

发行包为 Linux amd64。新安装使用 `install_v0.9.2.sh`；已有安装使用 `upgrade_v0.9.2.py` 校验包后更新管理程序和网页，保留已有配置与独立转发组件。默认监听 `0.0.0.0:18880`。

新的批量接口／路由协议需要配套前后端一起更新。WireGuard 服务仍使用接口级计划；回环／VPN 维护对象不因多选而绕过保护。

控制台仍无内置认证或 TLS；网络变更仍需确认和独立管理通道。详细范围见使用手册及安全说明。
