# FoXray Gateway 0.9.10

- 防火墙“全部规则”和“跨区域规则”替换为指定 SVG 图标；跨区域图标保留金黄色。
- WireGuard 接口管理增加接口 IP、Peer IP / AllowedIPs、Endpoint；运行中显示实际 Endpoint，停用 Peer 仍在列表中保留。
- 操作菜单增加“管理 Peer”：支持单独停用、重新启用，保留完整配置，不停止接口或其他 Peer。应用前预览，120 秒内确认，否则独立回退。
- Peer 启停关闭该配置的 SaveConfig，避免 wg-quick 在停止时覆盖已停用 Peer；接口路由保持原状，停用期间目标 Peer 不通信。重新启用时拒绝抢占其他运行中 Peer 已使用的相同 AllowedIPs。
- 网络变更确认弹窗与底部提示不再同时显示；关闭弹窗后可从底部继续确认或回退。

验证：前端构建、Go 全量测试、Peer 配置往返与持久回退测试；Linux 隔离网络命名空间验证单 Peer 启停不会删除其他 Peer 或接口；浏览器验证表格、Peer 操作、确认去重和图标。

升级仅重启 FoXray 管理服务，不自动修改业务 WireGuard 配置、不重启转发组件。
