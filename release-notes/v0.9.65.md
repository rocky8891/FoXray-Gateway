# FoXray Gateway v0.9.65 · 日常运维与界面稳定

发布于 2026-11-26。本节回顾 v0.9.50–v0.9.65。

## 主要更新

- HTTPS 支持自定义端口、可选 HTTP 跳转和证书状态展示。Let’s Encrypt 支持 HTTP 或 Cloudflare DNS 验证。Cloudflare 凭据可独立于 DDNS 配置，续期检查间隔可调。DDNS 支持 Cloudflare 和 DuckDNS，提供地址来源、连接测试、更新周期和操作日志。
- 管理访问支持账号密码、仅密码和关闭认证。顶栏用户菜单提供修改密码和退出。统一登录界面和设置页，备份可直接下载或保存到服务器指定目录。
- 网络批量菜单提供适用的纳管、删除、启用和停用操作。统一变更预览与确认流程，WireGuard 启动和开启自启会检查 systemd 屏蔽状态，失败任务记录具体步骤及可安全展示的错误。
- 统一设置卡片、输入框、表格宽度、复选框、弹窗与分页。Xray 规则编辑能搜索完整目标，浏览规则时保留翻页位置。复杂设置说明按规则、范围和使用条件分层呈现。
- 首页侧栏逐项展开，视图切换后能自动收起。刷新时保持隐藏的标题栏收起，默认空闲时间为 5 秒。首页动效默认跟随浏览器，可单独开启。修复 WARP 隐藏时 WireGuard 卡片拖动及狐狸图标裁剪。

## 下载与文档

- Linux amd64 在线安装包与校验文件见发行附件。
- 安装与升级手册使用 v0.9.65 配套版本。
