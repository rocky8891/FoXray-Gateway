# FoXray Gateway v0.9.67 · 接口保护与运维交互完善

发布于 2026-11-26。本里程碑合并 v0.9.50–v0.9.66 的更新记录，并增加独立的 WireGuard 接口保护开关。

## 接口保护

- WireGuard → 接口管理 → 行操作 → 接口保护，单独开启或关闭该接口的额外保护确认。
- 勾选多个接口后，通过批量操作 → 接口保护，统一设置所选接口。整批校验、一次写入，失败不部分保存。
- 旧配置默认保持 wg-home 受保护。自定义开关持久保存，显式关闭不会在管理服务重启后重新开启。
- 修改保护只写 FoXray 元数据，不启停接口，不修改地址、Peer、路由、SNAT 或开机自启。
- 保护状态同步到 WireGuard 列表及网络接口视图，并用于接口和相关路由操作的额外确认。VPN 模块归属、管理链路和常规参数校验仍独立保留。
- 接口重命名确认后继承保护状态；未确认的网络变更保留原有回退机制。

## 合并的运维与界面改进

- HTTPS 支持自定义端口、HTTP 跳转、自签名与 Let’s Encrypt HTTP / Cloudflare DNS 签发和续期；Cloudflare DNS 凭据可以独立于 DDNS 配置。DDNS 支持 Cloudflare 与 DuckDNS。
- 支持账号密码、仅密码及关闭认证；统一登录、修改密码和退出入口。配置备份支持下载或保存到服务器目录。
- 网络操作逐项预览、确认和回退，服务启动失败记录具体步骤与原因；WireGuard 单独修改备注不重启接口。
- SNAT 支持多源 IPv4/CIDR，防火墙视图展示不同来源规则和运行时诊断依据。
- 全局 i 说明采用分层列表，标题以冒号衔接正文；统一下拉菜单、列宽、筛选、分页、弹窗和重置按钮。
- WireGuard 对端隧道 IP 统一表格管理，支持单项和批量设置、各列排序与筛选。
- 首页各 WireGuard 接口的指标可独立拖动排序；修复首页直接编辑误改整页卡片清单的问题。随机主题保留已选择的展示卡片。
- 首页标题栏和侧边工具栏按可用空间自动收起，支持独立页面宽度与动效设置。

- 修正 Linux 域名诊断将 IPv4 映射地址误判为地址族不一致的问题。
