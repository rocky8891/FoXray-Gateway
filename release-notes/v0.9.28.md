# FoXray Gateway v0.9.28 · Peer 探测、路由保护与诊断

发布于 2026-11-25。本节回顾 v0.9.17–v0.9.28。

## 主要更新

- WireGuard Peer 增加握手、流量、路由与主动探测状态，可验证隧道地址或经 Peer 到达的远端地址。自动撤路由默认关闭，启用后仅处理指定的主路由表前缀，保留探测路径并记录撤销与恢复结果。
- 防火墙支持跨区域批量操作、所有区域视图、规则来源筛选与纳管确认。展示区域绑定、规则接口和服务定义的协议与端口。
- 诊断按本机入站或转发路径解析规则，区分内核选路、可能的 NAT 和静态推演，可选执行网关 TCP 建连验证。诊断结果可从日志查看、筛选、导出和重新执行。
- 首页标题栏使用狐狸按钮控制缩放收放，侧栏提供自动隐藏和键盘焦点回归。

## 下载与文档

- Linux amd64 在线安装包与校验文件见发行附件。
- 安装与升级手册使用 v0.9.28 配套版本。
