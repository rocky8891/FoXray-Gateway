# FoXray Gateway 0.9.8

- WireGuard 支持接口重命名、多个 AllowedIPs 及运行中编辑后自动重启，保留配置、名称、区域绑定、自启和运行状态回退。
- 优化 firewalld 规则读取，修正 nftables/iptables 状态显示；整合跨区域规则管理、运行时规则保护与独立回退。
- 跨区域规则图标、配色、说明入口及按钮间距统一；网络变更待确认改为自动弹窗。
- 修复主页满宽和自动隐藏标题栏组合的多余留白，优化侧栏隐藏入口的渐变玻璃效果。

本版保留既有安装配置；升级只重启 FoXray 管理服务，不重启 Xray、WARP、WireGuard 或 firewalld。
