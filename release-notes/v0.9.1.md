# FoXray Gateway v0.9.1 · 首次正式发布

发布于 2026-11-19。本节回顾 v0.9.1。

## 主要更新

- 使用 Go 与 React 提供一套控制台，用于 Xray 节点及订阅、WARP 隧道、WireGuard、服务器监控和 Linux 网络与防火墙。
- 支持真实连接检测、测速、出口选优、应用任务三态反馈及详情复制。接口、路由与策略规则使用变更计划，WireGuard 支持批量预览。
- 提供节点备份、主题和布局编辑、列表与宫格分页、跨页多选和 CSV 导出。上线 Linux amd64 安装包和管理程序独立更新工具。

## 下载与文档

- Linux amd64 在线安装包与校验文件见发行附件。
- 安装与升级手册使用 v0.9.1 配套版本。
