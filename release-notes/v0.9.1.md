# FoXray Gateway v0.9.1

发布日期：2026-11-19。发行平台：Linux amd64。许可证：GPL-3.0-only。

## 产品

面向自托管 Linux 网关的智能出口管理与可观测控制台。使用 Go 后端和 React 前端，将代理节点、VPN 隧道、服务器监控与系统网络操作整合到同一工作流。

## 功能范围

- Xray：节点导入与订阅、分组筛选、批量管理、真连接检测、测速评分、出口切换与选优、DNS、节点备份。
- WARP：当前官方隧道与候选端点分区管理；检测下拉支持 RTT、丢包、真延迟和速度，默认全选；候选支持恢复、重新发现、单选切换及独立隧道预检。
- WireGuard：接口与 peer 配置、服务动作、路由模式、LAN 转发计划、接口监控和汇总状态。
- 监控：服务器资源、接口流量、延迟、活动连接和 Xray 核心计数；采样、写入与页面刷新分别设置。
- 网络：接口、路由、策略路由、DNS、防火墙、SNAT 和端口转发；区分受管理配置与外部对象。
- 诊断与维护：任务进度、操作历史、检测/切换日志、备份、版本检查和管理程序更新回退。
- 界面：可定制主页、主题与卡片布局；统一列表／宫格分页，默认 10 项；筛选、排序、跨页选择、清单导出、省略号多级操作菜单，支持窄屏和键盘操作。
- 控件：按钮按用途统一为 42px 常规、32px 紧凑两档，共用 13px 字号、650 字重和 6px 圆角；工具栏、表格、卡片、弹窗、分页及纯图标按钮遵循同一规范，破坏性动作使用红色。
- 接口与任务：WireGuard 多选批量预览和独立确认；网络对象常用动作、策略纳管与受管理虚拟接口删除；任务区分成功／部分成功／失败，详细信息可复制。

## 检测与数据口径

Xray 默认测速地址为 `https://cachefly.cachefly.net/100mb.test`；WARP 默认使用 `https://speed.cloudflare.com/__down?bytes=10000000`。测速时长和下载量受配置限制，测速会消耗实际流量。真连接、ICMP、测速和业务流量分别展示。

缺测不补零；没有逐连接出口证据时，不将模块流量归给当前节点。LAN 诊断包含规则模拟，网关发起的实际连接不能替代客户端实测。

## 部署与安全边界

完整验证环境为 Rocky Linux 10、systemd 与 nftables；发行二进制为 Linux amd64。透明接管安装器当前要求 ens16。其他拓扑和发行版需单独验证；不提供通用路由器固件、集群控制面或经过验证的 Docker 方案。

默认监听全部 IPv4 网卡 `0.0.0.0:18880`，浏览器使用服务器实际 IP，无内置账号认证、TLS、RBAC 和多租户。使用 SSH 隧道、管理 VPN 或带独立认证的受控代理。网络变更应保留独立管理通道。
