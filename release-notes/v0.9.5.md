# FoXray Gateway v0.9.5

- 安装器按本机 IPv4 默认路由识别出口接口。`--check-topology` 可在安装前显示出口、LAN 网段及引导 DNS。
- Xray、LAN 透明接管、DNS、诊断和 WARP／WireGuard 网络辅助逻辑共用拓扑配置，支持通过 `/etc/foxray/topology.json` 显式设置。
- 新安装默认关闭 LAN 接管，可在确认客户端范围后启用。现有显式设置继续由运行配置管理。

使用配套的 `install_v0.9.5.sh` 新装，或按 `upgrade_v0.9.5_README.md` 更新已有部署。
