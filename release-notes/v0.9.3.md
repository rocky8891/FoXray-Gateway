# FoXray Gateway v0.9.3

首次发布：2026-11-20；本次更新：2026-11-22，版本保持0.9.3。

## 本次正式更新

- 防火墙服务状态与规则拆分读取，先显示运行状态；规则继续加载，未完整读取前保持编辑限制。区域详情复用于策略、允许服务与地址伪装，避免重复查询。
- 管理工具、查看区域和配置范围的字体与区域标题一致；策略配置项与规则概览标签一致，状态与运行时值使用统一绿色及字号，去除下划线。绑定接口、来源地址和允许服务标签改为绿色。

- 分页选择框按所有可能选项的最长文字、箭头与边距精确计算宽度，避免重叠和过宽；WireGuard受保护状态独立换行显示。
- 界面诊断结果自动展示后，当前浏览器将对应任务和关联日志同步标为已读，未展示的任务不批量标读。
- 服务总览在只读预览中支持随机主题本地试用与恢复；正式服务仍保留一分钟后自动保存。
- 防火墙服务标题改为服务管理，移除图标底块；各区域标题图标统一绿色并居中对齐，区域策略采用盾牌勾选图标。Xray／WARP服务管理使用各自产品图标，网络状态卡片图标按类别着色。

- WireGuard新增与现有接口支持用途备注；独立“编辑备注”不停止或重启接口，不改地址、Peer或路由，纳入变更预览、确认和120秒回退。移除凭接口名推断的“回家VPN”标签，保护状态与备注独立。
- 节点一览默认按页面高度自动计算每页数量，自动模式无需滚动；手动选择条数后保留选择，超出区域可滚动，并可切回自动模式。
- 节点管理将更多宽度分配给节点名称，分组、协议、状态、评分、延迟等辅助列按内容收紧。
- 网络／防火墙统计数字使用主题配色，深色统计卡片底色统一为rgb(28,35,47)。接口总数卡片清除搜索、列筛选及已选行。
- 接口行统一操作入口，编辑IP改为编辑；统一详情、编辑、停用、纳管图标的可见大小，更新设置与管理归属／来源图标。

- 重构防火墙工作区：区域策略、来源绑定、结构化高级规则和分类导航；默认行为修改纳入变更预览、影响提示、确认及自动回退。立即应用前校验全局运行时与永久配置差异，存在差异时阻止重载。
- 网络接口页使用可点击筛选统计卡片，支持地址族直接切换、友好路由表名称和待确认变更倒计时；保留页面标题及二级菜单。
- 统一网络与防火墙卡片配色、信息提示位置、接口标签及地址列宽；仅激活筛选时高亮。
- 修复主页指标字号随实时数值变化的问题，采用稳定字号与等宽数字。
- 更新用户提供的背景图片及 IP 规则图标。
- 自动列宽在最小表头宽度与最大480px内分配剩余空间，手动列宽保留；搜索框自适应工具栏。

## 主要变化

- 流量统计与连接详情默认按当前页内容自动列宽，支持拖动、浏览器记忆、双击恢复单列自动和整表恢复自动；最小宽度容纳完整表头及排序筛选，默认最大480px。
- 统一Xray、WARP、WireGuard服务设置的分组间距和表单对齐，WireGuard探测参数与对端IP分组显示；手机采用单列表单，长表格保留表头并横向滚动。
- 服务器历史图默认单排，保留明确保存的双排选择。各模块连接详情搜索框由实际204px加宽至408px，窄屏自适应。
- Xray“配置与同步”固定说明移至信息提示，待保存变更数量仍直接显示。

- 更换为用户提供的FoXray-Gateway-icon_v3.6A透明Logo，页眉、侧边入口和网站图标同步。
- LAN传统DNS智能接管支持UDP／TCP 53。同时覆盖已启用的本机接管范围，核心自身带标记的上游连接和VPN排除保持旁路，避免服务器DNS解析旁路。PC无需修改DNS地址；按自定义规则、强制代理开关和域名策略选择上游，故障后使用备用上游并冷却异常服务器。NAT恢复原DNS应答地址。
- DNS强制代理默认关闭，自定义规则始终优先；提供直连／代理上游清单。网关保留系统DNS、DoH／DoT、IPv6和VPN排除设置。
- 增加域名识别开关（默认关闭），使用核心HTTP Host、TLS／QUIC SNI与Webhook完整连接元组关联，不开启文件访问日志，不反查IP、不解密HTTPS正文。ECH外层名称可能不是真实访问域名。
- 诊断新增真实DNS查询和应答验证；LAN模式使用同一智能解析器并关联实际上游出站，同时明确标注为网关发起的规则模拟。纯TCP诊断关联核心事件，只报告建连完成，不再等同于目标应用可用。
- 新增原DNS IP规则、无效DNS地址兼容、故障上游、DNS事务校验及隔离网络实测；实测使用独立Xray核心，不改正式网络。

## 升级

使用配套`upgrade_v0.9.3.py`校验发行包后更新管理程序及网页；它按新增默认值规范化升级基线，保留显式设置，保留回退记录。随后保存并应用Xray代理配置，启用DNS接管规则与独立上游入口，该步骤会短暂重启核心。

智能接管限当前IPv4 LAN的传统DNS；明确阻断返回REFUSED，所有对应上游或代理均不可用时返回SERVFAIL，不伪造解析成功。域名识别在“设置 → Xray → 代理模式 → DNS分流与域名识别”开启。
