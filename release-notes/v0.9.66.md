# FoXray Gateway v0.9.66

- 防火墙诊断显示推演路径和转发判定、策略默认动作、WireGuard 伪装范围。明确拒绝时标记 SNAT 未到达。
- WireGuard 接口与 Peer 编辑表单默认遮住公钥，可按需查看明文。
- 共享表格固定首尾列，统一原生滚动条尺寸，并补充诊断结果表的工具栏。

### 同版本更新

- 防火墙的 firewalld、nftables 和 iptables SNAT 表单支持以英文逗号输入多个 IPv4 地址或 CIDR，同一条规则匹配任一来源。
- 诊断日志详情将结果标题与复制按钮放在同一行。候选表格允许调整中间列宽，保留横向滚动。
- 日志和区域管理表格将重置控件紧邻筛选。WireGuard 公钥显隐改用眼睛图标。

- WireGuard ICMP 探测目标统一为表格，支持单项编辑、搜索筛选及批量自动识别、保留地址改为手动、清空地址。更改保存后生效。
- 操作、检测、切换和诊断日志详情统一结果标题与复制按钮同排，标题采用 22px、内容标题采用 18px。
- 一级和二级导航按钮的背景模糊统一为 20px。

- 全局 i 说明统一支持普通文字、字段提示与组合片段的分层排版；重写服务管理、WireGuard、监控、网络和防火墙等说明，使用用途、范围和步骤组织内容。
- WireGuard 探测目标表将保存提示放入标题说明，总筛选移至标题行，全部数据列补充排序与筛选。

- i 说明中的短标题统一使用冒号衔接正文，保留多级列表。
- WireGuard 接口卡片内指标支持拖动与方向键排序，按接口独立保存；位置和圆形布局同步更新。
- 内置、自定义和混搭随机主题始终保留当前展示卡片选择，已隐藏的 WARP 等卡片不会被重新启用。

- WireGuard 探测目标表移除标题行总筛选，保留各数据列筛选；列筛选清除按钮统一为「重置」，参数与目标表使用标准间距。
