# FoXray Gateway v0.9.7

- 首页快捷工具栏贴齐卡片右上角，右侧空间不足时自动收起，按钮间距保持一致。
- Xray 启动任务核实服务运行状态。缺少核心配置、启动条件不满足或进程未运行时，任务提示和操作日志显示失败原因。
- WARP 仅为明确绑定其接口的程序选择隔离路由。安装客户端时也阻止网络准备服务启动，避免影响主机管理通信。

已有安装请参阅 `upgrade_v0.9.7_README.md`。Rocky Linux 9 离线安装请参阅 `prepare_offline_v0.9.7_README.md`。


### 2026-11-23：跨区域规则

- 防火墙新增“跨区域规则”，管理 firewalld Policy，按入口/出口区域、来源/目标地址、协议与端口限定转发。
- 提供新增、编辑、启停、删除、系统策略只读查看、运行时/永久状态与差异提示。
- 复用预览、应用、120 秒确认和独立回退；新增策略全局重载前执行配置差异检查，拒绝覆盖外部改动。
- 升级仅更新管理服务，不自动添加转发策略，不重载 firewalld。

- 修复仅永久保存的跨区域策略无法立即加载：保留额外运行时富规则，并在加载后还原临时永久副本；修正规则排序差异和策略自身差异误报，覆盖逐步骤失败与独立回退。
