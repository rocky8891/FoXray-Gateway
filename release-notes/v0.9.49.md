# FoXray Gateway v0.9.49 · 登录、HTTPS 与配置备份

发布于 2026-11-25。本节回顾 v0.9.29–v0.9.49。

## 主要更新

- 管理界面启用登录，支持新增账号、修改用户名与密码，初始账号需修改密码。HTTPS 支持自签名、导入 PEM 和使用 Certbot 通过 Cloudflare DNS 验证申请证书及续期。
- 配置备份覆盖 FoXray、Xray、WireGuard、WARP、网络连接、防火墙及默认路径下的 Komari 配置。支持密码加密、明文 ZIP、浏览器下载、服务器目录导出和离线恢复。保留旧 RSA 加密备份的恢复方式。
- 静态 JavaScript 与 CSS 支持 gzip，表格复用测得的列宽。防火墙表格按来源筛选，支持跨页全选，并在详情展示原生规则与 NAT 转换目标。诊断候选规则可定位到对应条目。
- 首页可按 WireGuard 接口展示独立指标卡，显示最近握手的 Peer 和端点。支持独立设置首页及模块宽度、浏览器背景、四圆样式和导航高亮。

## 下载与文档

- Linux amd64 在线安装包与校验文件见发行附件。
- 安装与升级手册使用 v0.9.49 配套版本。
